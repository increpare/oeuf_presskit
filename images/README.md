# Images Directory

This directory should contain all visual assets for your press kit.

## Required Files

### Screenshots
- `screenshot01.png` - Main gameplay screenshot
- `screenshot02.png` - Secondary gameplay screenshot
- `screenshot03.png` - Additional screenshot
- `screenshot04.png` - Additional screenshot
- `screenshot05.png` - Additional screenshot
- `screenshot06.png` - Additional screenshot (add more as needed)

**Recommended specifications:**
- Format: PNG or JPG
- Resolution: 1920x1080 (Full HD) or higher
- Aspect ratio: 16:9 preferred

### Logo and Icon
- `logo.png` - Game logo (with transparent background preferred)
- `icon.png` - Game icon/app icon

**Recommended specifications:**
- Format: PNG with transparency
- Logo: High resolution (at least 2000px width)
- Icon: Square format, at least 512x512px

### Optional Archives
- `screenshots.zip` - All screenshots bundled for easy download
- `logo.zip` - All logo variations bundled

## Tips

1. Use high-quality images that showcase your game's best features
2. Ensure screenshots are representative of actual gameplay
3. Include variety: UI, gameplay, different levels/scenes, key features
4. Avoid watermarks or overlays (this is for press use)
5. Name files descriptively if you add more (e.g., `boss-battle.png`, `level-3.png`)

## Placeholder Images

Until you have your actual game assets ready, you can use placeholder images from services like:
- https://placehold.co/
- https://placeholder.com/
- Or create simple colored rectangles with your game's name
