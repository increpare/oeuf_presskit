# Oeuf Presskit - Indie Game Press Kit Template

A comprehensive press kit template for indie game developers. This template provides all the essential sections and placeholder content that journalists and press outlets need to cover your game effectively.

## What is a Press Kit?

A press kit (or presskit) is a package of promotional materials about your game designed specifically for journalists, content creators, and media outlets. It makes it easy for press to find all the information, images, videos, and assets they need to write articles, create videos, or otherwise cover your game.

## Features

This press kit template includes:

✅ **Complete Structure** - All standard sections journalists expect to see
✅ **Professional Design** - Clean, responsive CSS styling that works on all devices
✅ **Easy Customization** - Simply replace placeholder text with your game's information
✅ **Media Ready** - Organized sections for screenshots, videos, logos, and downloadable assets
✅ **SEO Friendly** - Proper HTML structure with semantic markup
✅ **Print Friendly** - CSS print styles for physical press kits

## Sections Included

1. **Factsheet** - Quick reference information (developer, release date, platforms, pricing, links)
2. **Description** - Compelling overview of your game
3. **History** - Development timeline and background
4. **Features** - Key gameplay features and selling points
5. **Videos** - Embedded trailers and gameplay videos
6. **Images** - Screenshots and visual assets
7. **Logo & Icon** - Downloadable branding materials
8. **Awards & Recognition** - Accolades and achievements
9. **Selected Articles** - Press coverage and reviews
10. **Additional Links** - Social media, store pages, and community links
11. **About** - Studio information and team details
12. **Contact** - Press contact information

## How to Use

### 1. Clone or Download

Get this template on your local machine or web hosting.

### 2. Customize Content

Open `index.html` and replace all placeholder text in square brackets `[Like This]` with your actual game information:

- `[Game Title]` - Your game's name
- `[Studio Name]` - Your studio/company name
- `[Description text]` - Your game's description
- And so on...

### 3. Add Visual Assets

#### Images
Place your image files in the `images/` directory:
- `screenshot01.png` through `screenshot06.png` (or more)
- `logo.png` - Your game logo
- `icon.png` - Your game icon
- Optionally create `.zip` archives for easy bulk downloads

See `images/README.md` for detailed specifications.

#### Videos
Place your video files in the `videos/` directory:
- `trailer.mp4` - Main trailer
- `gameplay.mp4` - Gameplay footage

Or simply update the YouTube embed codes in the HTML.

See `videos/README.md` for detailed specifications.

### 4. Customize Styling (Optional)

The `style.css` file contains all the visual styling. You can customize:
- Colors (change the gradient colors in the header)
- Fonts (update the font-family declarations)
- Layout (adjust grid columns, spacing, etc.)
- Branding (make it match your game's aesthetic)

### 5. Deploy

Upload the entire directory to your web hosting:
- Web server (Apache, Nginx, etc.)
- GitHub Pages
- Netlify, Vercel, or similar services
- Your game's domain (e.g., `yourgame.com/presskit`)

### 6. Share with Press

Once live, share your press kit URL with:
- Journalists and publications
- Content creators and streamers
- Include the link in press releases
- Add it to your game's website footer
- Share it on social media

## Tips for Success

### Content Tips
- **Be concise** - Journalists are busy; make information easy to find
- **Be accurate** - Double-check all dates, prices, and links
- **Be complete** - Don't leave empty sections; remove sections that don't apply
- **Be current** - Update your press kit as your game evolves
- **Boilerplate** - Write a great 2-3 sentence boilerplate description that can be copy-pasted

### Asset Tips
- **High quality** - Provide the highest resolution assets possible
- **Variety** - Include diverse screenshots showing different aspects
- **Authentic** - Use actual gameplay footage, not mockups
- **Accessible** - Provide downloadable files, not just embedded content
- **Organized** - Name files clearly and logically

### Technical Tips
- **Fast loading** - Optimize images for web (use compression)
- **Mobile friendly** - Test on phones and tablets (the template is responsive)
- **Print ready** - The CSS includes print styles for physical media kits
- **Archive option** - Consider creating a PDF version for email distribution
