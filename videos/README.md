# Videos Directory

This directory should contain video files for your press kit.

## Required Files

### Trailers and Gameplay
- `trailer.mp4` - Main trailer (announcement or launch trailer)
- `gameplay.mp4` - Gameplay footage video

**Recommended specifications:**
- Format: MP4 (H.264 codec)
- Resolution: 1920x1080 (Full HD) minimum
- Frame rate: 30 or 60 fps
- Bitrate: High quality (10-20 Mbps for 1080p)
- Audio: AAC codec, stereo

## Tips

1. Keep trailers concise (1-2 minutes for announcement, 30-60 seconds for launch)
2. Gameplay videos should be 2-5 minutes showing core mechanics
3. Add subtitles if there's dialogue (accessibility)
4. Export at high quality - journalists may need to use clips
5. Also upload to YouTube/Vimeo and embed in the press kit

## Hosting Considerations

Large video files can make your press kit slow to load. Consider:
- Hosting videos on YouTube or Vimeo and embedding them
- Providing download links separately
- Using a CDN for large files
- Keeping file sizes under 100MB when possible

## Alternative

If you don't have video files yet:
- Create placeholder text files explaining what will go here
- Link only to YouTube/Vimeo versions (no local files needed)
- Focus on getting screenshots first, videos can come later
